# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork the Repository**: Create your own copy of the repository by clicking the "Fork" button on GitHub.
2. **Clone the Repository**: Clone your fork locally using `git clone`.
3. **Create a Feature Branch**: Create a new branch for your feature or fix using `git checkout -b feature-name`.
4. **Make Changes**: Implement your changes and ensure your code is clean and tested.
5. **Commit Changes**: Commit your changes with descriptive commit messages using `git commit -m "Description of changes"`.
6. **Push to Your Fork**: Push your feature branch to your remote repository using `git push origin feature-name`.
7. **Submit a Pull Request**: Open a pull request against the `main` branch of the original repository describing the changes you made.

Thank you for helping improve this project!
