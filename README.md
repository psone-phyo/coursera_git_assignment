# Simple Interest Calculator

A simple command-line Bash script that calculates simple interest based on user inputs for principal, rate of interest, and time period.

## Description
Simple interest is a quick and easy method of calculating the interest charge on a loan or investment. This script prompts the user to enter:
1. **Principal amount**: The initial amount of money.
2. **Rate of interest**: The annual interest rate (in percentage).
3. **Time period**: The time duration in years.

It then computes and outputs the total simple interest accrued over the given duration.

## Formula
$$\text{Simple Interest} = \frac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$$

## Usage
```bash
bash simple-interest.sh
```
